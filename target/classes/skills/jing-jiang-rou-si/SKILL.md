# 京酱肉丝制作技能

## 何时使用此技能
- 用户询问"京酱肉丝怎么做"或"家庭版京酱肉丝做法"
- 需要制作下饭菜、儿童餐或北方风味家常菜
- 想要学习"酱爆"技法或肉丝上浆滑油技巧
- 寻找甜面酱调配比例与葱丝搭配建议
- 了解传统吃法（豆皮卷/春饼卷）与现代改良版本

## 创作指导（烹饪执行标准）

### 第一步：食材准备与预处理
**核心食材清单**：
- **主料**：猪里脊肉 260g（切丝前可冷冻30分钟更易切）。
- **腌料**：蛋清1个、料酒1勺、盐少许、白胡椒粉少许、淀粉1大勺、清水1勺、香油封油。
- **酱汁**：甜面酱3大勺（推荐王致和或六必居）、白糖1勺、香油1勺（可选加番茄酱或蚝油提鲜）。
- **配菜**：大葱白1根（切细丝铺底）、千张豆皮或春饼（蒸热备用）。

### 第二步：关键工艺流程
1.  **肉丝上浆**：肉丝加腌料抓匀至发粘，最后淋香油封住水分，腌制15分钟以上。
2.  **滑油定型**：油温四成热（约120℃）下肉丝，用筷子快速拨散，变色即捞出控油（避免过老）。
3.  **炒酱裹汁**：
    -   留底油小火炒甜面酱至冒泡、油亮发红。
    -   转大火倒入肉丝，快速翻炒使酱汁均匀包裹每一根肉丝。
    -   关火前可淋少许老抽调色，确保"见油不见酱"。
4.  **装盘呈现**：将炒好的肉丝盛入铺满葱丝的盘中，或直接用豆皮/春饼卷食。

### 第三步：口感验收与搭配
-   **肉丝状态**：入口滑嫩不柴，酱汁浓稠挂壁，无多余汤汁。
-   **风味平衡**：咸甜适中，酱香突出，葱丝解腻增香。
-   **经典吃法**：取一张豆皮，放葱丝、肉丝，卷起食用；或搭配米饭、馒头。

## 厨师小贴士
-   **关于选酱**：甜面酱是灵魂，务必选老字号品牌，避免用普通豆瓣酱替代。
-   **关于火候**：滑油时油温不可过高，否则肉丝易老；炒酱时先小火后大火，防止糊锅。
-   **关于葱丝**：只用葱白部分，切得越细越好，可提前泡冰水使其更脆爽。
-   **关于改良**：若喜欢微辣，可在炒酱时加少许干辣椒段；若喜酸甜口，可适当增加白糖比例。
