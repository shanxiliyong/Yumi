org.springframework.ai.tool.method.MethodToolCallback  是什么

MethodToolCallback 是 Spring AI 用来把普通 Java 方法包装成「LLM 可调用工具（Function Calling / Tool Call）」 的核心实现类。
作用：将你定义的 Java 方法封装成 ToolCallback，当大模型判断需要调用工具时，Spring AI 自动执行这个 Java 方法，并把返回结果送回 LLM。
